Why it works

Key Features of Website Auto Translate

Automatic Content Scanning

The moment a page loads in a non-English language, every visible text node is collected client-side — no template edits, no manual string marking, nothing to maintain per page.

Google Translate API Integration

Translations are generated through the Google Translate API using your own key, configured from a single field in Settings — no separate translation service to manage.

Smart Translation Caching

Every source string and language pair is stored once in a dedicated cache model. Repeat visits, and repeat visitors, are served from cache instead of calling the API again.

Batched & Deduplicated Requests

Duplicate strings on the same page are translated once, and requests are chunked to respect Google's batch limits — keeping API calls, and cost, to a minimum.

Safe Fallback on Failure

If the API key is missing, invalid, or a request fails, the original text is shown and left uncached — visitors never see a broken or blank page.

Race-Condition Safe Cache Writes

Concurrent requests for the same string are handled with database savepoints, so simultaneous visitors never create duplicate or conflicting cache entries.

One-Click Enable in Settings

Turn auto translation on or off, and manage your API key, from a single toggle in General Settings — no developer mode, no code changes required.

Works With Any Website Language

The module reads whatever language is active on the page and translates into it automatically, so every language you install on your website is covered from day one.

How it works

Setup & Behaviour Walkthrough

From adding your API key to seeing translations served instantly from cache on a second visit — here's the full picture.

1

Configure the Module

From Settings → Website, enable Auto Translation and paste in your Google Translate API key. That's the entire setup.

2

Switch the Website Language

A visitor picks a different language from the website's language selector, and the page reloads with that language's HTML tag set.

3

Live Client-Side Translation

The page's text nodes are sent to the server in one batch call and swapped in place as soon as translations come back — the underlying page templates are never touched.

4

Cache Fills Automatically

Every new translation is saved to the Auto Translation Cache. The next visitor, or the same visitor's next page, is served from cache with no additional API call.

5

Graceful Fallback

If translation isn't enabled, the key is missing, or the API call fails, the page simply shows the original text — nothing breaks and nothing is cached as a false translation.
